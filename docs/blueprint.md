# **App Name**: AyushConclave- Arogya Expo

## Core Features:

- Landing Page Showcase: Showcase information about the Arogya Expo on the landing page.
- Informational Pages: Implement 10 additional informational pages with details on Ayush.
- Interactive Map: Integrate an interactive map showing exhibitors and key locations at the event.
- Registration Form: Allow users to register for the event via a web form.
- AI Design Assistance: Use Gemini to help designing the website.

## Style Guidelines:

- Primary color: Natural green (#6CA33F) for a connection to health and nature.
- Background color: Soft muted green (#E2EAD9) to complement the primary color.
- Accent color: Warm gold (#FCBA55) for highlights and important calls to action.
- Body and headline font: 'Cabin' sans-serif to balance readability and modern appeal. Note: currently only Google Fonts are supported.
- Use icons related to health and Ayurvedic practices; should be line-based and in a light color.
- Emphasize white space to provide good balance to dense informational content.
